# Nodra Apps

Official public distribution repository for **Nodra** application releases.

This repository is used only for publishing installable application builds and release information.  
**Application source code is not published here.**

## Android

The current stable Android release is:

**Nodra 1.4.2**

Download the APK from the **Releases** section of this repository.

### Installation

1. Download the APK from the latest GitHub Release.
2. Open the downloaded file on your Android device.
3. If Android asks for permission to install apps from this source, allow it for your browser or file manager.
4. Install Nodra.

> Android may display a warning for applications installed outside Google Play. Make sure you download Nodra only from this official repository.
